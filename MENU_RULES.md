# How to add a menu line (you or an agent)

Do this when a real job needed a direction that did not exist.
Do not do this in the same breath as drawing.

## Allowed

- Append one or more **complete specs** to the matching JSON list.
- Keep the file valid JSON (quoted strings, commas, no trailing comment).
- A line must be executable without a second guess.

Good:
`Corner shop price board: handwritten marker on laminated sheets, numbers bigger than words, tape stains allowed`

Bad:
`minimal`, `bold`, `modern`, `fun`, `clean SaaS`, `more like Apple`

## Tests for a new line

1. Could two agents build the same kind of thing from only this sentence?
2. Does it name materials, type behavior, structure, or a ban — not a mood?
3. Is it distinct from every existing line in that file? If it is “Swiss grid but blue,” skip it.
4. Website structure lines must say how you move (scroll / card / form / timer / rooms).
5. Visual lines must imply palette + type + what images are allowed.

## Agents may update menus only if

- The human said `add to the menus` or `expand menus`.
- They add **at least 4** new lines, then stop.
- They do **not** sample in the same turn they edited the menu.
- They print the new lines in the reply so the human can veto.

If the human did not ask to expand, do not touch the files.
Draw from what exists.
